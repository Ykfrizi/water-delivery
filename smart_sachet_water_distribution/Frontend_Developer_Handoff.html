Smart_App — Frontend Developer Handoff

API base: {APP_URL}/api/v1 — replace with your environment (e.g. local XAMPP host or production HTTPS URL). All routes below are relative to /api/v1.

1. Cross-cutting (all apps)

TopicFrontend responsibility
FormatJSON over HTTPS; send Accept: application/json.
AuthenticationLaravel Sanctum: store token from login/register securely; send Authorization: Bearer <token> on protected routes.
Three personasCustomer, vendor, and admin use different auth endpoints and tokens — wrong role returns 403.
LogoutPOST …/auth/logout with Bearer token; clear local token.
ErrorsHandle 401 (unauthenticated), 403 (forbidden / wrong role), 404, 422 (validation — surface field errors).
IdentifiersVendors in URLs use slug. Orders use order_number in paths such as orders/{order}.

6. Necessary non-screen items

  • Secure token storage per app/persona on mobile (Keychain / EncryptedSharedPreferences / equivalent).
  • Environment config for API base URL per build flavor.
  • 422 validation mapped to forms (register, profile, cart, checkout).
  • Pagination for list endpoints that support per_page.
  • Images — backend returns URLs (e.g. logo_url); handle placeholders and failures.
  • Order lifecycle — show only sensible next actions; invalid transitions return API errors.
